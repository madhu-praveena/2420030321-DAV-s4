# ChurnIQ Front-end Prototype

Open `index.html` in a browser or with VS Code Live Server.

**Important:** This is the original interactive UI prototype supplied with the project ZIP. The KPI values, customer records, model comparison scores and prediction rule are illustrative demo content. The prediction form does not call the Python model and the chatbot is not connected to an LLM. A visible prototype notice has been added to the page so these values are not mistaken for experimental results.

The reproducible machine-learning implementation is in the repository root (`src/`). Connecting this front end to a trained model through a Flask/FastAPI endpoint is a future integration task.
