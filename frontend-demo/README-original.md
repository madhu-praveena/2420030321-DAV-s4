# ChurnIQ — Customer Churn Prediction AI Copilot

This is a redesigned, pastel-teal interactive web app based on the uploaded Customer Churn Prediction abstract. The abstract describes data preprocessing, EDA, and comparison of Logistic Regression, Decision Tree, Random Forest, SVM, KNN and XGBoost using Accuracy, Precision, Recall, F1-Score and ROC-AUC. fileciteturn0file0L14-L29

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html`.
4. Right-click → Open with Live Server, or open `index.html` directly in a browser.

## AI chatbot
The included ChurnAI is a local demo assistant: it responds to common project questions without an API key. It is not connected to a live LLM. For a real AI chatbot, connect the chat UI to a backend/API.

## ML note
The prediction form currently uses a transparent frontend demo scoring rule so the project works immediately. Replace that function with a Flask/FastAPI/Spring endpoint connected to your trained model for actual predictions.


## Dark accent edition
The interface keeps the light pastel base but adds rich dark teal sections, including the hero, AI Copilot header, model/analytics accents, sidebar AI card, and a dark status strip for stronger visual contrast.
